Concept and reasoning 05 / 18

A stack preserves a path

  • The root remains the starting point.
  • A push adds a destination.
  • Back removes the current destination.

Discuss / predictDoes going back mean deleting the record?

Concept and reasoning 10 / 18

An explicit commit boundary

Swift excerpt · see practice download for context

func commit(id: UUID, title: String) {
    guard let index = requests.firstIndex(
        where: { $0.id == id }
    ) else { return }
    requests[index].title = title
}
