W02-Lab: ให้แอปตอบสนองด้วย State

ก่อนเริ่มต้น

คุณจะสร้างแอป DiceRoller สำหรับทอยลูกเต๋าจำลองตามบทเรียน Update the UI with state ของ Apple โดยแยก DiceView สำหรับลูกเต๋าแต่ละลูก ใช้ @State และ Button สุ่มแต้ม 1...6 พร้อมแอนิเมชัน ใช้ ForEach แสดงจำนวนลูกเต๋าตาม @State ของหน้าหลัก ป้องกันช่วงตัวเลขผิดพลาดด้วย .disabled ปรับขนาดลูกเต๋าให้รองรับสูงสุด 5 ลูก และตกแต่งด้วยสีพื้นหลังกับ SF Symbols โหมดพาเลตต์

[ภาพตัวอย่างแอป — ผู้สอนเพิ่มภายหลัง]

  • แยก Custom View (DiceView) และใช้พร็อพเพอร์ตี้ร่วมกับ String Interpolation
  • เชื่อม Button และ trailing closure เข้ากับ @State พร้อมแอนิเมชัน withAnimation
  • สร้างจำนวน View แบบไดนามิกด้วย ForEach และป้องกันค่าขอบเขตด้วย .disabled
  • ปรับขนาดยืดหยุ่นด้วย maxWidth/maxHeight, aspectRatio, .labelStyle(.iconOnly) และตกแต่งสีด้วย Asset Catalog กับ .foregroundStyle

เตรียม: Mac ที่ติดตั้ง Xcode พร้อม iPhone/iPad Simulator หรือ iPad ที่ติดตั้ง Swift Playgrounds, แอป Pages/Word หรือแอปเอกสารที่ส่งออก PDF ได้ และบัญชี Canvas สำหรับส่งงาน เคยสร้างและ Run แอปตาม Week 01 ได้แล้ว

สร้างโปรเจ็กต์ใหม่ตามภารกิจที่ 1 ไม่ต้องดาวน์โหลดไฟล์หรือใช้โปรเจ็กต์เดิม เลือก Simulator บน Mac จึงไม่ต้องใช้บัญชีสำหรับ signing เครื่องจริง ภาพส่งงานควรมีเฉพาะแอปหรือโค้ดที่เกี่ยวข้อง ไม่ติดรายละเอียดบัญชีหรือข้อมูลส่วนตัว

ภารกิจ

1. สร้าง Custom View สำหรับลูกเต๋า (Create a custom view) 15 นาที

  1. Xcode บน Mac: สร้างโปรเจ็กต์ iOS App ใหม่ (File > New > Project... > iOS > App) ตั้งชื่อ Product Name เป็น DiceRoller เลือก Interface เป็น SwiftUI และ Language เป็น Swift
  2. Swift Playgrounds บน iPad: สร้าง App ใหม่ (New Playground > App หรือปุ่ม + > App) แล้วตั้งชื่อเป็น DiceRoller
  3. สร้างไฟล์ SwiftUI View ใหม่ชื่อ DiceView (บน Mac เลือก File > New > File from Template... > SwiftUI View ตั้งชื่อ DiceView; บน iPad เพิ่มไฟล์ Swift ใหม่ชื่อ DiceView.swift)
  4. แทนที่โค้ดภายใน body ของ DiceView ด้วยรูปหน้าลูกเต๋า Image(systemName: "die.face.1") ลองเปลี่ยนตัวเลขท้ายชื่อจาก 1 ถึง 6 เพื่อดูรูปหน้าลูกเต๋าทั้ง 6 ด้านใน SF Symbols
  5. เพิ่มพร็อพเพอร์ตี้ var numberOfPips: Int = 1 ใน DiceView ก่อน body เพื่อแทนจำนวนแต้มบนลูกเต๋า การกำหนดค่าเริ่มต้น = 1 ทำให้ไม่ต้องแก้การเรียก DiceView() ใน #Preview
  6. ใช้ String Interpolation \(numberOfPips) แสดงภาพลูกเต๋าตามค่าพร็อพเพอร์ตี้ แล้วเพิ่ม modifier .resizable() เพื่อให้ภาพยืดขยายได้ และจำกัดขนาดด้วย .frame(width: 100, height: 100)

DiceView.swift

import SwiftUI

struct DiceView: View {
    var numberOfPips: Int = 1

    var body: some View {
        Image(systemName: "die.face.\(numberOfPips)")
            .resizable()
            .frame(width: 100, height: 100)
    }
}

#Preview {
    DiceView()
}

ตรวจผล: เห็นภาพลูกเต๋าขนาด 100×100 พอยต์ตรงกลาง Preview ลองเปลี่ยนค่าเริ่มต้นของ numberOfPips เป็นเลขอื่นระหว่าง 1 ถึง 6 เพื่อตรวจว่ารูปเปลี่ยนตามค่าพร็อพเพอร์ตี้ แล้วเปลี่ยนกลับเป็น 1

2. เพิ่มปุ่มทอยลูกเต๋าและอัปเดต View ด้วย @State (Add a button & Use state) 15 นาที

  1. ใน DiceView.swift ครอบ Image และ modifier ด้วย VStack เพื่อวางปุ่มไว้ด้านล่างลูกเต๋า
  2. ภายใน VStack ถัดจาก Image เริ่มพิมพ์ Button เลือกตัวสร้างที่มี titleKey (หรือ title) กับ action แทนที่ชื่อปุ่มด้วย "Roll" แล้วกด Tab ไปที่ action: () -> Void และกด Return เพื่อเปลี่ยนเป็น trailing closure { ... }
  3. ใน closure ของปุ่ม เขียนคำสั่งสุ่มแต้ม 1 ถึง 6 ด้วย numberOfPips = Int.random(in: 1...6) สังเกตว่าจะเกิด compiler error เพราะพร็อพเพอร์ตี้ทั่วไปของ struct แก้ไขค่าใน body ไม่ได้ และ SwiftUI ไม่ได้เฝ้าดูพร็อพเพอร์ตี้ทุกตัวโดยอัตโนมัติ
  4. เปลี่ยน numberOfPips เป็นพร็อพเพอร์ตี้ @State โดยใส่ @State private ข้างหน้า (ใส่ private เสมอเพราะ view เป็นเจ้าของ state ของตัวเอง ไม่ให้ view อื่นเข้ามาแทรกแซง) แล้วลองกดปุ่ม Roll หลายครั้ง
  5. เพิ่ม .buttonStyle(.bordered) ต่อท้าย Button เพื่อใส่กรอบแยกปุ่มออกจากรูปลูกเต๋า และครอบคำสั่งสุ่มค่าด้วย withAnimation { ... } เพื่อให้การเปลี่ยนภาพลูกเต๋าค่อย ๆ จางเปลี่ยน (fade) อย่างนุ่มนวล

DiceView.swift

import SwiftUI

struct DiceView: View {
    @State private var numberOfPips: Int = 1

    var body: some View {
        VStack {
            Image(systemName: "die.face.\(numberOfPips)")
                .resizable()
                .frame(width: 100, height: 100)

            Button("Roll") {
                withAnimation {
                    numberOfPips = Int.random(in: 1...6)
                }
            }
            .buttonStyle(.bordered)
        }
    }
}

#Preview {
    DiceView()
}

ตรวจผล: กดปุ่ม Roll สองสามครั้งแล้วเห็นภาพลูกเต๋าเปลี่ยนแต้มพร้อมแอนิเมชัน หากกดแล้วภาพไม่เปลี่ยน ตรวจว่าใส่ @State private หน้า numberOfPips แล้ว

เก็บภาพที่ 1: หน้าจอหรือ Preview ของ DiceView ที่มีปุ่ม Roll แบบมีกรอบและทอยเปลี่ยนแต้มแล้ว

3. สร้างการแสดงผลลูกเต๋าแบบไดนามิก (Create a dynamic display of dice) 20 นาที

  1. เปิด ContentView.swift แทนที่เนื้อหาใน VStack ด้วยหัวข้อ Text("Dice Roller").font(.largeTitle.lowercaseSmallCaps()) คง .padding() ต่อท้าย VStack ไว้
  2. เพิ่ม HStack ที่มี DiceView() สามตัวเรียงกัน ลองกดทอยลูกเต๋าแต่ละลูก จากนั้นแทนที่ DiceView() สามตัวด้วย ForEach(1...3, id: \.description) { _ in DiceView() } เพื่อให้สร้าง subview ตามช่วงตัวเลข
  3. เพิ่มพร็อพเพอร์ตี้ @State private var numberOfDice: Int = 1 ใน ContentView ก่อน body แล้วเปลี่ยนช่วงใน ForEach จาก 1...3 เป็น 1...numberOfDice
  4. ถัดจาก HStack ของลูกเต๋า เพิ่ม HStack อีกชุดที่มีสองปุ่มสำหรับลดและเพิ่มจำนวนลูกเต๋า พร้อม .padding() ต่อท้าย HStack ของปุ่มตามโค้ดด้านล่าง

ContentView.swift — ก่อนใส่ .disabled

HStack {
    Button("Remove Dice") {
        numberOfDice -= 1
    }

    Button("Add Dice") {
        numberOfDice += 1
    }
}
.padding()
  1. ลดจำนวนลูกเต๋าให้เหลือ 1 ลูก แล้วกดปุ่ม Remove Dice อีกครั้ง สังเกตว่า Preview หรือแอปจะ crash เพราะช่วง 1...0 ไม่ถูกต้อง เก็บภาพข้อผิดพลาดนี้ก่อนแก้ไข
  2. ป้องกันการกดเมื่อเหลือ 1 ลูกด้วย .disabled(numberOfDice == 1) ที่ปุ่ม Remove Dice และป้องกันไม่ให้มีเกิน 3 ลูก (เพราะขนาด 100×100 พอดีหน้าจอได้ 3 ลูก) ด้วย .disabled(numberOfDice == 3) ที่ปุ่ม Add Dice จากนั้นครอบการเปลี่ยนค่าในปุ่มทั้งสองด้วย withAnimation

เก็บภาพที่ 2: หน้าจอเกิดข้อผิดพลาด (Preview Crashed หรือ runtime error) เมื่อกด Remove Dice จนช่วงกลายเป็น 1...0 ก่อนใส่ .disabled

ContentView.swift — หลังใส่ .disabled และ withAnimation

import SwiftUI

struct ContentView: View {
    @State private var numberOfDice: Int = 1

    var body: some View {
        VStack {
            Text("Dice Roller")
                .font(.largeTitle.lowercaseSmallCaps())

            HStack {
                ForEach(1...numberOfDice, id: \.description) { _ in
                    DiceView()
                }
            }

            HStack {
                Button("Remove Dice") {
                    withAnimation {
                        numberOfDice -= 1
                    }
                }
                .disabled(numberOfDice == 1)

                Button("Add Dice") {
                    withAnimation {
                        numberOfDice += 1
                    }
                }
                .disabled(numberOfDice == 3)
            }
            .padding()
        }
        .padding()
    }
}

#Preview {
    ContentView()
}

ตรวจผล: ปุ่ม Remove Dice ถูกปิดใช้งานเมื่อมีลูกเต๋า 1 ลูก และปุ่ม Add Dice ถูกปิดใช้งานเมื่อมีลูกเต๋า 3 ลูก ไม่สามารถกดจนแอป crash ได้อีก

4. ปรับขนาดให้รองรับลูกเต๋าเพิ่มและใช้รูปในปุ่ม (Adapt the interface & Use images in button labels) 15 นาที

  1. ใน ContentView.swift เพิ่มขีดจำกัดลูกเต๋าเป็น 5 ลูกโดยเปลี่ยน .disabled(numberOfDice == 3) เป็น .disabled(numberOfDice == 5) แล้วกด Add Dice จนครบ 5 ลูก สังเกตว่า HStack ให้ขนาดตามที่ขอจนลูกเต๋าล้นขอบจอ
  2. เปิด DiceView.swift เปลี่ยน .frame(width: 100, height: 100) เป็นเฟรมยืดหยุ่น .frame(maxWidth: 100, maxHeight: 100) เพื่อให้รูปลูกเต๋าย่อขนาดลงได้ แต่เมื่อมี 4–5 ลูก ภาพจะถูกยืดในแนวตั้ง จึงต้องใส่ .aspectRatio(1, contentMode: .fit) ต่อท้ายเพื่อบังคับสัดส่วน 1:1 (สี่เหลี่ยมจัตุรัส)
  3. กลับไปที่ ContentView.swift เพิ่มอาร์กิวเมนต์ systemImage: "plus.circle.fill" ในปุ่ม Add Dice และ systemImage: "minus.circle.fill" ในปุ่ม Remove Dice
  4. ต่อท้าย .padding() ของ HStack ปุ่ม เพิ่ม .labelStyle(.iconOnly) เพื่อซ่อนข้อความบนปุ่มแต่ยังเก็บชื่อปุ่มไว้ให้ฟีเจอร์อย่าง VoiceOver อ่านได้ และเพิ่ม .font(.title) เพื่อขยายขนาดไอคอนปุ่ม

DiceView.swift — ปรับ Image modifiers

Image(systemName: "die.face.\(numberOfPips)")
    .resizable()
    .frame(maxWidth: 100, maxHeight: 100)
    .aspectRatio(1, contentMode: .fit)

ContentView.swift — ปรับ HStack ของปุ่มลดและเพิ่มลูกเต๋า

HStack {
    Button("Remove Dice", systemImage: "minus.circle.fill") {
        withAnimation {
            numberOfDice -= 1
        }
    }
    .disabled(numberOfDice == 1)

    Button("Add Dice", systemImage: "plus.circle.fill") {
        withAnimation {
            numberOfDice += 1
        }
    }
    .disabled(numberOfDice == 5)

.padding()
.labelStyle(.iconOnly)
.font(.title)

ตรวจผล: กดปุ่มไอคอน + จนมีลูกเต๋าครบ 5 ลูก ลูกเต๋าทุกอันย่อขนาดลงเป็นสี่เหลี่ยมจัตุรัสเรียงพอดีในหน้าจอ และปุ่มด้านล่างแสดงเฉพาะไอคอนลบและบวกขนาดใหญ่

เก็บภาพที่ 3: หน้าจอที่แสดงลูกเต๋าครบ 5 ลูกขนาดสี่เหลี่ยมจัตุรัสเรียงพอดีจอ พร้อมปุ่มไอคอนลบและบวก

5. ปรับแต่งสีและดีไซน์ของแอป (Improve your app design) 15 นาที

  1. Xcode บน Mac: เปิด Assets ใน Project Navigator คลิกปุ่ม + ด้านล่าง เลือก Color Set ตั้งชื่อว่า App Background เปิด Attributes Inspector เลือกช่องสีแล้วกำหนดค่า Red เป็น 0.208, Green เป็น 0.478 และ Blue เป็น 0.613
  2. Swift Playgrounds บน iPad: หากไม่สร้าง Color Set ใน Asset Catalog ให้วางโค้ดนี้ต่อท้ายไฟล์ ContentView.swift เพื่อให้ใช้ .appBackground ได้เหมือนกันทุกประการ: extension ShapeStyle where Self == Color { static var appBackground: Color { Color(red: 0.208, green: 0.478, blue: 0.613) } }
  3. ใน ContentView.swift เพิ่ม .foregroundStyle(.white) ต่อท้ายหัวข้อ Text("Dice Roller") และที่ท้าย VStack นอกสุด (ต่อจาก .padding()) ให้เพิ่ม .frame(maxWidth: .infinity, maxHeight: .infinity) เพื่อให้ขยายเต็มจอ ตามด้วย .background(.appBackground) และ .tint(.white)
  4. เปิด DiceView.swift เปลี่ยนชื่อสัญลักษณ์เป็นแบบทึบ "die.face.\(numberOfPips).fill" ลองใส่ .foregroundStyle(.white) ก่อนจะเห็นว่าตัวลูกเต๋าเป็นสีขาวแต่จุดแต้มโปร่งใส จึงให้เปลี่ยนเป็น .foregroundStyle(.black, .white) เพื่อใช้โหมดพาเลตต์ของ SF Symbols กำหนดสีหลัก (จุดแต้ม) เป็นสีดำ และสีรอง (ตัวลูกเต๋า) เป็นสีขาว

ContentView.swift — ฉบับสมบูรณ์

import SwiftUI

struct ContentView: View {
    @State private var numberOfDice: Int = 1

    var body: some View {
        VStack {
            Text("Dice Roller")
                .font(.largeTitle.lowercaseSmallCaps())
                .foregroundStyle(.white)

            HStack {
                ForEach(1...numberOfDice, id: \.description) { _ in
                    DiceView()
                }
            }

            HStack {
                Button("Remove Dice", systemImage: "minus.circle.fill") {
                    withAnimation {
                        numberOfDice -= 1
                    }
                }
                .disabled(numberOfDice == 1)

                Button("Add Dice", systemImage: "plus.circle.fill") {
                    withAnimation {
                        numberOfDice += 1
                    }
                }
                .disabled(numberOfDice == 5)
            }
            .padding()
            .labelStyle(.iconOnly)
            .font(.title)
        }
        .padding()
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .background(.appBackground)
        .tint(.white)
    }
}

#Preview {
    ContentView()
}

DiceView.swift — ฉบับสมบูรณ์

import SwiftUI

struct DiceView: View {
    @State private var numberOfPips: Int = 1

    var body: some View {
        VStack {
            Image(systemName: "die.face.\(numberOfPips).fill")
                .resizable()
                .frame(maxWidth: 100, maxHeight: 100)
                .aspectRatio(1, contentMode: .fit)
                .foregroundStyle(.black, .white)

            Button("Roll") {
                withAnimation {
                    numberOfPips = Int.random(in: 1...6)
                }
            }
            .buttonStyle(.bordered)
        }
    }
}

#Preview {
    DiceView()
}

ตรวจผล: พื้นหลังสี .appBackground ขยายเต็มหน้าจอ หัวข้อและปุ่มมีสีขาว ลูกเต๋าเป็นสีขาวทึบแต้มสีดำ สามารถทอยแต้มแต่ละลูกและเพิ่ม/ลดจำนวนลูกเต๋าได้ตั้งแต่ 1 ถึง 5 ลูก

เก็บภาพที่ 4: หน้าจอแอป Dice Roller ฉบับสมบูรณ์ที่มีพื้นหลังเต็มจอ ลูกเต๋าสีขาวแต้มสีดำ และปุ่มสีขาว

เพิ่มเติม. ขยายความสามารถของแอป (Extend your app — ไม่บังคับ) 5 นาที
