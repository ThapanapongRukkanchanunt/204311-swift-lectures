01 · The framework contract 05 / 29

Inversion of Control

  • An ordinary call starts when application code chooses to invoke a function.
  • For a callback, application code supplies behavior and the framework invokes it later.
  • Developers choose the response. The framework coordinates when it runs.

01 · State and transitions 09 / 29

State Is Memory That Affects Output

  • State: information that changes and affects output.
  • Event: something the app responds to.
  • Rule: a condition or calculation that guides behavior.
  • Derived output: calculated from current facts.

01 · Read and write state 10 / 29

A Minimal Stateful View

Swift / SwiftUI excerpt

struct QueueView: View {
    @State private var waiting = 3

    var body: some View {
        VStack {
            Text("Waiting: \(waiting)")
            Button("Join queue") { waiting += 1 }
        }
    }
}

@State lets SwiftUI track waiting. When it changes, SwiftUI automatically updates the parts of the screen that read it.

Recompute Is Not Relaunch

03 · State and binding 19 / 29

A Child Can Edit the Parent’s State

Swift / SwiftUI excerpt

@State private var waiting = 3

// In the parent’s body:
QueueControls(waiting: $waiting)

// In QueueControls:
@Binding var waiting: Int
  • @State stores the value for the parent.
  • $waiting passes a connection to that value.
  • @Binding lets the child read and change it without storing a second count.

Initial Values

04 · Property observers 24 / 29

Before and After a Property Changes

Swift / SwiftUI excerpt

struct QueueCount {
    var waiting = 0 {
        willSet { print("Next:", newValue) }
        didSet { print("Previous:", oldValue) }
    }
}
var queue = QueueCount()
queue.waiting = 4
  • willSet runs before assignment and can read newValue.
  • didSet runs after assignment and can read oldValue.

04 · Mutating methods 25 / 29

Methods That Change a Structure

Swift / SwiftUI excerpt

struct QueueCount {
    var waiting = 0
    mutating func join() { waiting += 1 }
}
var queue = QueueCount()
queue.join()
  • mutating allows this method to change the structure’s stored properties.
  • Use var for an instance you intend to change.

04 · static and self 26 / 29

The Type and the Current Instance

Swift / SwiftUI excerpt

struct QueueCount {
    static let capacity = 10
    var waiting: Int
    init(waiting: Int) {
        self.waiting = waiting
    }
}
  • QueueCount.capacity belongs to the type.
  • self.waiting refers to this instance’s property.
  • In the initializer, plain waiting is the input parameter.

05 · Summary 28 / 29

Events, Views and Data

  • The framework runs the button’s supplied code after a press.
  • A change to @State updates the interface that depends on it.
  • A parent can pass a binding so a child edits the same value.
  • Structures group data and behavior into reusable value types.
