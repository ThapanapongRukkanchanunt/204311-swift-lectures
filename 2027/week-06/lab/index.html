เตรียมโปรเจกต์

ดาวน์โหลด catch-up starter Week 06 แล้วแตกไฟล์ สร้างโปรเจกต์ SwiftUI App ใหม่ใน Xcode หรือ App ใหม่ใน Swift Playgrounds เก็บ App entry เดิมไว้ เพิ่มไฟล์ Swift ตาม README และแทนเฉพาะ ContentView.swift ของโปรเจกต์ใหม่ Run ให้ผ่านก่อนแก้ตามภารกิจ ไม่ทับโปรเจกต์เดิม Run แล้วเห็น Library help หนึ่งรายการและช่องกรอกชื่อ

ภารกิจ

1. เพิ่มข้อมูลจาก draft 15 นาที

  1. เพิ่มปุ่ม Add หลัง TextField ตามตัวอย่าง
  2. กรอก Library help แล้ว Add สองครั้ง เพื่อให้มีชื่อซ้ำ
  3. ทดลองช่องว่างล้วน ต้องไม่เพิ่มรายการ

ContentView.swift — ใน VStack หลัง TextField

Button("Add") {
    let title = draft.trimmingCharacters(in: .whitespacesAndNewlines)
    guard !title.isEmpty else { return }
    requests.append(Request(title: title))
    draft = ""
}

ตรวจผล / แก้ปัญหา: เพิ่มชื่อซ้ำได้แต่แต่ละรายการมี ID ของตนเอง ถ้าเพิ่มแล้วหายตรวจว่า requests เป็น State

เก็บภาพที่ 1: รายการชื่อซ้ำอย่างน้อยสองแถว

2. แก้สถานะและลบตาม ID 20 นาที

  1. แทน Text(item.title) ใน List ด้วย VStack ที่มี Text ชื่อ ปุ่ม Toggle status และปุ่ม Remove
  2. ใช้โค้ดปุ่มด้านล่าง เปลี่ยนสถานะรายการกลางหนึ่งครั้ง แล้วลบอีกแถวหนึ่ง
  3. เพิ่ม Text(item.isOpen ? "Open" : "Closed") ใน row เพื่อให้เห็นสถานะ

ContentView.swift — ภายใน closure ของ List ใน row VStack

Button("Toggle status") {
    if let index = requests.firstIndex(where: { $0.id == item.id }) {
        requests[index].isOpen.toggle()
    }
}
Button("Remove") {
    requests.removeAll { $0.id == item.id }
}

ตรวจผล / แก้ปัญหา: ลบเฉพาะแถวที่กดและเปลี่ยนสถานะเฉพาะ ID ที่เลือก ถ้าชื่อซ้ำหายหลายแถวตรวจว่าไม่ได้ลบด้วย title

เก็บภาพที่ 2: แถวที่ยังอยู่หลังลบพร้อมสถานะ Open/Closed

3. กรองโดยไม่ลบต้นฉบับ 20 นาที

  1. เพิ่ม @State private var onlyOpen = false ก่อน body
  2. เพิ่ม computed property visible ตามตัวอย่าง และเปลี่ยน List(requests) เป็น List(visible)
  3. เพิ่ม Toggle("Open only", isOn: $onlyOpen) ก่อน List แล้วทดสอบเปิดและปิด filter
  4. จงใจนึกถึงวิธีลบด้วย requests.remove(at: 0) อธิบายด้วยข้อมูลที่มี closed อยู่ก่อนว่าเหตุใดวิธีนี้ผิด โดยไม่ต้องทำลายข้อมูลจริง

ContentView.swift — ก่อน body

var visible: [Request] {
    requests.filter { !onlyOpen || $0.isOpen }
        .sorted { $0.title < $1.title }
}

ตรวจผล / แก้ปัญหา: เมื่อปิด filter รายการ closed กลับมา หากหายถาวรตรวจว่าไม่ได้เขียนผล filter ทับ requests

เก็บภาพที่ 3: ขณะเปิด Open only ที่เห็นเฉพาะรายการเปิด

4. เพิ่ม empty state และทดสอบขอบเขต 20 นาที

  1. ก่อน List เพิ่ม if visible.isEmpty แล้วแสดงข้อความตามตัวอย่าง
  2. เปลี่ยนทุกรายการเป็น Closed เปิด Open only ให้เห็น No matching requests
  3. ปิด filter ลบทีละ ID จนหมดให้เห็น No requests yet จากนั้น Add อีกครั้ง
  4. เพิ่มชื่อที่ยาวและทดสอบข้อความใหญ่ ปุ่มแต่ละแถวควรมี accessibilityLabel ที่ระบุชื่อคำขอ

ContentView.swift — ก่อน List

if visible.isEmpty {
    Text(requests.isEmpty
        ? "No requests yet"
        : "No matching requests")
}

ตรวจผล / แก้ปัญหา: แยกกรณีไม่มีข้อมูลกับ filter ไม่ตรงได้ และกลับมาเพิ่มรายการหลังว่างได้

เก็บภาพที่ 4: No matching requests ขณะยังมีข้อมูลใน source

เพิ่มเติม (ไม่บังคับ) · 5 นาที

เพิ่มตัวเลือกเรียงชื่อกลับลำดับ โดยคง source array และ ID เดิม ไม่ต้องส่งภาพเพิ่ม

ยินดีด้วย!

คุณใช้ ID คงที่กับรายการที่เพิ่ม ลบ และกรองได้ พร้อมข้อความเมื่อไม่พบข้อมูล
