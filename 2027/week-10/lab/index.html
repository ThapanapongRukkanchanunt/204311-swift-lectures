ภารกิจ

1. เชื่อมสอง model และสร้างข้อมูล 20 นาที

  1. อ่าน Models.swift ระบุว่าคำขอมี category ได้หนึ่งค่าหรือ nil และ category มีหลาย requests
  2. เพิ่มปุ่ม Add samples ที่สร้าง Category("Library") ด้วย initializer name: แล้ว context.insert(category)
  3. สร้าง ServiceRequest(title: "Opening hours", category: category) และ ServiceRequest(title: "Quiet room", category: category) ใส่ context แล้ว save พร้อม catch/rollback
  4. กดปุ่มเพียงครั้งเดียวและแสดง category.name ใน row ใช้ ?? "Uncategorized" เมื่อไม่มี

ตรวจผล / แก้ปัญหา: สองคำขอเชื่อม category เดียวกัน ถ้าไม่มีข้อมูลตรวจ insert และ error จาก save

เก็บภาพที่ 1: สองคำขอที่แสดงหมวด Library

2. ค้นหาและแยก empty state 20 นาที

  1. เพิ่ม State search และ TextField("Search titles", text: $search)
  2. เพิ่ม visible ตาม excerpt แล้วเปลี่ยน List ให้ใช้ visible
  3. แสดง No matching requests เมื่อ visible ว่างแต่ requests ไม่ว่าง ทดลอง room, ข้อความที่ไม่ตรง และช่องว่างเปล่า

ContentView.swift — ก่อน body

var visible: [ServiceRequest] {
    requests.filter {
        search.isEmpty ||
        $0.title.localizedCaseInsensitiveContains(search)
    }
}

ตรวจผล / แก้ปัญหา: การล้าง search คืนรายการครบ ไม่เขียนผล filter ทับ source

เก็บภาพที่ 2: ผลค้นหา room ที่เหลือคำขอตรงเงื่อนไข

3. ตรวจความหมายของการลบหมวด 20 นาที

  1. เพิ่มปุ่ม Rename category ที่แก้ categories.first?.name เป็น Library services แล้ว save ตรวจชื่อในทั้งสองคำขอ
  2. เพิ่มปุ่ม Remove category สำหรับข้อมูลฝึก ใช้ if let category = categories.first { context.delete(category) } แล้ว save พร้อม catch
  3. ก่อนลบล้าง search หลังลบต้องเหลือคำขอสองรายการแต่ category เป็น Uncategorized
  4. ถ้าคำขอหายให้ตรวจ deleteRule ว่าเป็น .nullify ไม่ใช่ .cascade

ตรวจผล / แก้ปัญหา: ลบหมวดแต่เก็บคำขอไว้ตามกฎที่เลือก

เก็บภาพที่ 3: คำขอยังอยู่พร้อม Uncategorized หลังลบหมวด

4. ตรวจ lifecycle และ relaunch 15 นาที

  1. เพิ่ม @Environment(\.scenePhase) private var phase ก่อน body
  2. ต่อ onChange ตาม excerpt ที่ VStack และคง explicit save ของปุ่มเดิมไว้
  3. สลับแอปไป background แล้วกลับสามครั้ง ตรวจจำนวนคำขอไม่เพิ่ม จากนั้นปิดและเปิดใหม่
  4. ห้ามเรียก Add samples จาก onAppear หรือ onChange ตรวจ message เมื่อ save ล้มเหลว

ContentView.swift — modifier ของ VStack

.onChange(of: phase) { _, newPhase in
    if newPhase == .background {
        do { try context.save() }
        catch { message = "Save pending" }
    }
}

ตรวจผล / แก้ปัญหา: กลับมาแล้วไม่มี duplicate และ relaunch ยังแสดงคำขอโดยไม่มีหมวด

เก็บภาพที่ 4: หลัง relaunch มีสองคำขอและไม่มีข้อมูลซ้ำ
