Content and reference are different

  • Text fits a structured field or document.
  • Media has binary content and format.
  • A filename points to content but is not the content.

Concept and reasoning 08 / 19

Loading may suspend or fail

Swift excerpt · see practice download for context

guard let item = selection else { return }
do {
    let data = try await item.loadTransferable(type: Data.self)
    try Task.checkCancellation()
    // Validate representation, then accept or store it.
} catch is CancellationError {
    // Keep the previously accepted attachment.
} catch {
    message = "Image could not be loaded."
}
