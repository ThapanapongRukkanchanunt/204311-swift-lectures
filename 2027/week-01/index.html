3 / Explain the repair 11 / 25

Theory: quality means justified tradeoffs

Refreshing more often can improve freshness—and use more battery and data.

Useful + resilient

Solve the urgent task, including interruption and uncertainty.

Efficient + inclusive

Respect resources and attention; support varied abilities and contexts.

Trustworthy

Collect justified data and make its use visible and controllable.

4 / Name the roles 15 / 25

Theory: from source to a running app

Build time · on the Mac

  1. Swift source + assets
  2. Xcode invokes compiler + SDK
  3. An app build

Swift is a language. Xcode is an IDE. An SDK supplies platform interfaces and build resources.

Run time · device or simulator

  1. Your app + framework APIs
  2. iOS / iPadOS services
  3. Display · storage · network · sensors

The OS mediates protected resources. The simulator supports testing but cannot replace every hardware check.

This responsibility map separates development tools from runtime layers.

Read further: Apple · Tools and distribution

4 / Name the structure 16 / 25

Theory: a framework owns part of the work

Language

A way to express values, logic and types.

Library

Reusable code your code calls.

Framework

Structure, conventions and runtime behavior that call your code at defined points.

Swift is the language. SwiftUI supplies a framework for interfaces.

Next week: how events and state updates move through that framework.

Theory: imperative and declarative UI

Imperative: specify update steps. Declarative: describe the UI for its state.

Theory: the problems behind the milestones

  1. 2008 · iPhone SDK + App StoreOfficial device APIs, tools and a distribution channel.
  2. UIKit · Event-driven interfacesCompose platform views; coordinate their updates.
  3. 2014 / 2015 · SwiftA modern type-safe language, then open-source development.

6 / Name the choices 23 / 25

Theory: native, cross-platform and mobile web

Native

Platform SDKs and frameworks.
Gain: direct platform integration.
Consider: platform-specific expertise.

Cross-platform

Share substantial code through a framework.
Gain: shared implementation.
Consider: platform adaptations and dependencies.

Mobile web / PWA

Browser delivery with progressive capabilities.
Gain: reach through a link.
Consider: browser and API support.

These categories overlap: SwiftUI spans Apple platforms; cross-platform tools can render native components. Shared code still requires platform testing.
