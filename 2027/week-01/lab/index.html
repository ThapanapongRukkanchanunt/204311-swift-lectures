เก็บภาพหน้าจอเมื่อพบคำว่า “เก็บภาพ” แล้วรวมตามลำดับเป็น PDF หนึ่งไฟล์ ใช้ข้อความสมมติและหลีกเลี่ยงข้อมูลบัญชีหรือข้อมูลส่วนบุคคลในภาพ

ภารกิจ

1 สร้างและรันโปรเจ็กต์ 15 นาที

เลือกทำเส้นทางที่ตรงกับเครื่องของคุณ

Mac — Xcode

  1. เลือก Create New Project แล้วเลือก iOS > App
  2. ตั้ง Product Name เป็น CampusLife, Interface เป็น SwiftUI, Language เป็น Swift และ Organization Identifier เป็น edu.example.cs311 เลือก None สำหรับ Testing System และ Storage หากมีช่องเหล่านี้
  3. บันทึกโปรเจ็กต์ในโฟลเดอร์ของคุณ ใช้ deployment target ตามที่ผู้สอนแจ้ง แล้วเลือก iPhone Simulator ที่ติดตั้งเป็นอุปกรณ์สำหรับรัน
  4. กด Run หรือ Command-R เพื่อเปิดแอปใน Simulator

iPad — Swift Playgrounds

  1. เลือก New Playground > App จากหน้ารวมโปรเจ็กต์
  2. เปลี่ยนชื่อโปรเจ็กต์เป็น CampusLife แล้วเปิดโปรเจ็กต์
  3. แตะ Run App เหนือพื้นที่โค้ดเพื่อเปิดแอป

ตรวจผล: เห็นหน้าจอเริ่มต้นจากเทมเพลต

เก็บภาพที่ 1: หน้าจอแอปเริ่มต้นที่รันได้

หาก Xcode ขอ signing ให้ตรวจว่าเลือก Simulator ไม่ใช่อุปกรณ์จริง บน iPad ให้สร้างชนิด App ไม่ใช่ playground book

2 สร้างข้อความต้อนรับ 20 นาที

  1. เปิดไฟล์ที่มี @main เช่น CampusLifeApp.swift หรือ MyApp.swift หา ContentView() ภายใน WindowGroup โดยยังไม่แก้ไฟล์นี้
  2. เปิด ContentView.swift หา var body: some View { ... }
  3. แทนที่เฉพาะเนื้อหาภายในวงเล็บปีกกาของ body ด้วยโค้ดด้านล่าง เก็บ import SwiftUI, โครง struct และโค้ด preview เดิมไว้

ContentView.swift: โค้ดบางส่วนสำหรับวางภายใน body

VStack(spacing: 16) {
    Text("Campus Life")
        .font(.largeTitle)

    Text("Welcome to campus")
        .font(.title2)

    Text("Today: Explore the library")
        .font(.body)
}
.padding()
.multilineTextAlignment(.center)

ไฟล์ที่มี @main เป็นจุดเริ่มต้นของแอป ส่วน ContentView อธิบายหน้าจอ VStack จัดข้อความในแนวตั้ง และ .font ปรับขนาดตัวอักษร

ตรวจผล: รันใหม่แล้วเห็นข้อความสามส่วนเรียงจากบนลงล่าง หากมี error ให้ตรวจว่าวางโค้ดภายใน body และวงเล็บปีกกาครบ

3 เพิ่มสัญลักษณ์ 15 นาที

เพิ่มโค้ดต่อไปนี้หลังบรรทัด VStack(spacing: 16) { ก่อน Text("Campus Life")

ContentView.swift: โค้ดบางส่วนสำหรับเพิ่มภายใน VStack

Image(systemName: "building.2")
    .font(.largeTitle)
    .foregroundColor(.blue)
    .accessibilityHidden(true)

รูปนี้ใช้ตกแต่ง ข้อความบอกความหมายครบแล้ว จึงซ่อนเฉพาะรูปจากโปรแกรมอ่านหน้าจอด้วย .accessibilityHidden(true)

ตรวจผล: รันใหม่แล้วเห็นรูปเหนือชื่อแอป หากรูปไม่แสดง ให้ตรวจตัวสะกด building.2 รวมจุด

4 ปรับหน้าจอเป็นของคุณ 15 นาที

  1. ใน ContentView.swift เปลี่ยนข้อความต้อนรับและสถานะเป็นภาษาอังกฤษสั้น ๆ เกี่ยวกับมหาวิทยาลัย คงชื่อ Campus Life
  2. เปลี่ยนรูปเป็น book.fill หรือ leaf.fill และเปลี่ยนสีรูปจาก .blue เป็น .green หรือ .purple
  3. เปลี่ยน spacing: 16 เป็น spacing: 24 แล้วรันใหม่ สังเกตว่าช่องว่างเปลี่ยนอย่างไร
  4. ตรวจการอ่านทั้งแนวตั้งและแนวนอน บน Simulator ใช้ Device > Rotate Left หรือ Rotate Right บน iPad หมุนเครื่องขณะเปิดแอป

ตรวจผล: รูปและข้อความครบ ไม่ทับกันหรือถูกตัด หากข้อความยาวเกินไปให้ย่อข้อความแล้วรันใหม่

เก็บภาพที่ 2: หน้าจอที่ปรับข้อความ รูป สี และระยะห่างแล้ว

5 ทดลองสร้างและแก้ error 15 นาที

  1. ใน ContentView.swift เปลี่ยน Text("Campus Life") เป็น Tex("Campus Life") โดยตั้งใจลบตัว t
  2. ลอง Run แล้วเปิด error ข้างบรรทัดหรือ Issue Navigator ใน Xcode บน iPad แตะ Show All Issues
  3. เก็บภาพที่ 3: ให้เห็น Tex และข้อความ error ที่เครื่องมือแสดง ก่อนแก้ไข
  4. แก้ Tex กลับเป็น Text แล้วเพิ่ม Ready: ที่ต้นข้อความสถานะ
  5. รันใหม่ ตรวจว่า error หายไปและเห็นสถานะใหม่ครบทั้งสองแนว
  6. เก็บภาพที่ 4: หน้าจอหลังแก้สำเร็จที่เห็น Ready:

Tex เป็นชื่อที่ไม่มีอยู่ จึงทำให้สร้างแอปใหม่ไม่สำเร็จ ลองคิดว่าเหตุใดภาพเก่าที่ค้างใน Simulator จึงไม่ได้แปลว่าโค้ดใหม่ทำงานแล้ว

ตรวจผล: แอปรันได้และเห็นข้อความ Ready: หากยังมี error ให้ตรวจว่าแก้กลับเป็น Text และอ่าน error แรกที่ยังเหลือ

ลองเพิ่มเติม (5 นาที — ไม่บังคับ)

หลังทำแอปเสร็จ ลองเพิ่มข้อความสั้นอีกหนึ่งบรรทัดใน VStack ใช้ .font(.body) แล้วตรวจว่ายังอ่านได้เมื่อเพิ่มขนาดข้อความในการตั้งค่า Accessibility ไม่ต้องส่งภาพเพิ่ม

ยินดีด้วย!

คุณสร้างและปรับหน้าจอ SwiftUI พร้อมทดลองแก้ error ได้แล้ว

6 รวมภาพและส่ง PDF 10 นาที

  1. เปิด Pages, Word หรือแอปเอกสารที่คุณใช้ สร้างเอกสารใหม่แล้วแทรกภาพที่ 1–4 ตามลำดับ ภาพละหนึ่งหน้า
  2. ใส่ชื่อใต้ภาพ: 1. First run, 2. My screen, 3. Error, 4. Fixed
  3. ส่งออกเป็น PDF ชื่อ W01_รหัสนักศึกษา.pdf
  4. เปิด PDF ตรวจว่ามีครบ 4 หน้า รูปไม่ถูกตัด และอ่านข้อความ error ในภาพที่ 3 ได้ หากอ่านไม่ชัด ให้ครอบภาพเฉพาะบริเวณโค้ดกับ error แล้วแทนภาพเดิม
  5. อัปโหลด PDF ใน Canvas Assignment นี้ แล้วตรวจว่าไฟล์ที่ส่งเปิดได้ เก็บโปรเจ็กต์ไว้ใช้ต่อ

ส่งเฉพาะ PDF รวมภาพทั้ง 4 ภาพ ไม่ต้องแนบโปรเจ็กต์หรือรายงานเพิ่มเติม
