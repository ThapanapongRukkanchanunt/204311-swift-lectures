W03-Lab

สร้าง Pick-a-Pal ด้วย List, TextField และ Binding

ก่อนเริ่มต้น

สร้างแอปเพิ่มชื่อในรายการ สุ่มเลือกชื่อ และเลือกได้ว่าจะลบชื่อที่สุ่มแล้วหรือไม่ ทำตาม Create dynamic content ของ Apple ครบ 6 ส่วนสร้างแอป คำแนะนำภาษาไทยต่อไปนี้เรียงตามต้นฉบับ

เมื่อจบ คุณจะสร้างรายการจาก array เชื่อมช่องกรอกและ Toggle กับ state และตรวจพฤติกรรมเมื่อรายการว่างได้ ข้อมูลอยู่ในหน่วยความจำและเริ่มใหม่เมื่อเปิดแอปใหม่ ไม่มีการบันทึกถาวร

  • ใช้ Xcode บน Mac พร้อม iPhone Simulator หรือ Swift Playgrounds บน iPad ที่สร้าง App ได้ ทบทวน Button, @State และ VStack จาก Week 2
  • เปิด tutorial ได้ทางอินเทอร์เน็ตสำหรับขั้นตอนต้นฉบับ ไม่ต้องมีบัญชีหรือ backend ใหม่
  • ใช้ชื่อตัวอย่างที่ไม่ซ้ำและชื่อเล่นของคุณตามขั้นตอน ไม่ใช้ชื่อจริงหรือนามสกุล เตรียม Pages, Word หรือแอปเอกสารสำหรับรวมภาพเป็น PDF ไม่ถ่ายบัญชีหรือข้อมูลส่วนตัว
  • เก็บไฟล์ App ที่เครื่องมือสร้างไว้ แก้ ContentView.swift ตามตำแหน่งที่ระบุ โค้ดในกรอบเป็นส่วนย่อย ไม่ใช่ไฟล์เต็ม

ภารกิจ

1. สร้างรายการ — Create a list 10 นาที

Apple · Create a list

  1. สร้างโปรเจกต์แอปใหม่ชื่อ Pick-a-Pal แล้วเปิดไฟล์ ContentView.swift
  2. ใน body คง VStack และ .padding() แล้วแทนรูปโลกกับข้อความเริ่มต้นด้วย List ที่มีชื่อสมมติสี่รายการ ลอง Run ให้เห็นแถวก่อนเปลี่ยนเป็นข้อมูลแบบ array
    แสดง/ซ่อนโค้ด: ContentView.swift — ภายใน VStack
    List {
    Text("Elisha")
    Text("Andre")
    Text("Jasmine")
    Text("Po-Chun")
}
  3. ลบ Text ทั้ง 4 บรรทัดภายใน List จากนั้นเพิ่มตัวแปร names โดยวางไว้ภายใน struct ContentView ก่อน var body ตัวแปรนี้เก็บรายชื่อเป็น array ของ String และใช้ @State เพื่อให้หน้าจออัปเดตเมื่อรายชื่อเปลี่ยน ตอนนี้หน้าจอจะยังไม่แสดงรายชื่อ เพราะเราจะนำข้อมูลจาก names มาแสดงในขั้นตอนถัดไป
    แสดง/ซ่อนโค้ด: ContentView.swift — ภายใน struct ก่อน body
    @State private var names: [String] = [
    "Elisha", "Andre", "Jasmine", "Po-Chun"
]
  4. ใช้คำสั่ง ForEach เพื่อสร้างหนึ่งแถวต่อหนึ่งชื่อภายใต้ List ลองลากรายการใน Preview เพื่อดูการเลื่อน

    ForEach อ่านข้อมูลทีละรายการจาก names โดยใช้ name แทนชื่อที่กำลังอ่าน แล้วสร้าง Text(name) เพื่อแสดงชื่อนั้น ส่วน id ใช้ระบุว่าแต่ละแถวเป็นรายการใด ในตัวอย่างนี้ใช้ชื่อเป็นตัวระบุ จึงควรใช้ชื่อที่ไม่ซ้ำกัน

    \.description เป็น key path ที่บอกให้ Swift อ่าน property ชื่อ description ของสมาชิกแต่ละตัว สำหรับ String ค่า description ก็คือข้อความนั้นเอง ดังนั้น id: \.description จึงใช้ข้อความของแต่ละชื่อเป็นตัวระบุแถว
    แสดง/ซ่อนโค้ด: ContentView.swift — ภายใน List
    ForEach(names, id: \.description) { name in
    Text(name)
}

ตรวจผล / แก้ปัญหา: เห็นสี่แถวจาก names และเลื่อนได้ หากรายการว่างให้ตรวจว่า ForEach อยู่ใน List และ names ไม่ใช่ array ว่าง

เก็บภาพที่ 1: รายการชื่อสมมติสี่แถวที่สร้างจาก names และ ForEach

2. รับชื่อจาก TextField — Use a text field to enter names 22 นาที

Apple · Use a text field to enter names

  1. เพิ่ม nameToAdd เป็น @State ก่อน body ค่าเริ่มต้นข้อความว่างทำให้ Swift อนุมานชนิด String ได้
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน body
    @State private var nameToAdd = ""
  2. เพิ่ม TextField หลัง List แต่ยังอยู่ใน VStack ใช้ $nameToAdd เพื่อส่ง binding ให้ช่องกรอกอ่านและแก้ state นี้ได้
    แสดง/ซ่อนโค้ด: ContentView.swift — หลัง List
    TextField("Add Name", text: $nameToAdd)
  3. ต่อ .onSubmit ที่ TextField เพื่อเพิ่มชื่อเมื่อกด Return และล้างช่องกรอก ลองเพิ่มชื่อใหม่สองชื่อ แล้วลอง Return ตอนช่องว่างเพื่อสังเกตแถวว่างก่อนแก้ในขั้นถัดไป
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier ของ TextField
    .onSubmit {
    names.append(nameToAdd)
    nameToAdd = ""
}
  4. เพิ่มเงื่อนไขเมื่อชื่อไม่ใช่ข้อความว่าง ถึงจะทำการเพิ่มชื่อ กด Run ใหม่ ทดสอบ Return ว่างอีกครั้ง: จำนวนแถวต้องไม่เพิ่ม
    แสดง/ซ่อนโค้ด: ContentView.swift — แทน .onSubmit เดิม
    .onSubmit {
    if !nameToAdd.isEmpty {
        names.append(nameToAdd)
        nameToAdd = ""
    }
}
  5. Xcode: เลือก Product → Run และเลือก iPhone Simulator ที่ติดตั้งไว้ แตะช่องกรอก ถ้าแป้นพิมพ์ไม่แสดง ให้ใช้ I/O → Keyboard → Toggle Software Keyboard ใน Simulator บน iPad: Run ใน Swift Playgrounds แล้วแตะช่องกรอก ใช้ Return บนแป้นพิมพ์จริงหรือบนจอ
  6. เพิ่ม .autocorrectionDisabled() ที่ TextField เพื่อไม่ให้ระบบแก้ชื่ออัตโนมัติ แล้ว Run ใหม่ ทดสอบพิมพ์ชื่อสมมติที่ระบบเคยพยายามแก้
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier ของ TextField ก่อน .onSubmit
    .autocorrectionDisabled()
  7. Xcode อาจหยุด Preview ขณะ Run ให้กด Resume/ปุ่มลูกศรบน Preview canvas เพื่อเปิดอีกครั้ง จะเปิด Simulator ค้างไว้ก็ได้ หากต้องการซ่อน Debug area ใช้ View → Debug Area → Hide Debug Area บน iPad ให้หยุด Run แล้วกลับตัวแก้ไขและ Preview ของแอป ไม่ต้องหาเมนู Xcode
ดูภาพอ้างอิงเพิ่มเติมจาก Apple

ตรวจผล / แก้ปัญหา: เพิ่มชื่อเล่นของคุณในช่อง Add Name แล้วกด Return ตรวจว่ารายการมีทั้งหมด 5 ชื่อ ได้แก่ ชื่อตัวอย่างเดิม 4 ชื่อและชื่อเล่นของคุณ และช่อง Add Name ถูกล้าง หากมีชื่อที่เพิ่มระหว่างทดลอง ให้หยุดแล้ว Run ใหม่ก่อนเพิ่มชื่อเล่น ทดสอบกด Return ขณะช่องว่าง: จำนวนชื่อต้องยังเป็น 5

เก็บภาพที่ 2: รายการที่มีทั้งหมด 5 ชื่อ ได้แก่ ชื่อตัวอย่างเดิม 4 ชื่อและชื่อเล่นของคุณ โดยช่อง Add Name ว่างหลัง Return

3. สุ่มสมาชิก — Pick a random element from an array 15 นาที

Apple · Pick a random element from an array

  1. เพิ่ม pickedName ก่อน body เพื่อเก็บชื่อที่สุ่มได้
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน body
    @State private var pickedName = ""
  2. เพิ่ม Text เหนือ List เพื่อแสดง pickedName ถ้ายังไม่มีชื่อให้ใช้ช่องว่างหนึ่งตัวเพื่อจองความสูง ต่างจากข้อความว่างที่ไม่จองพื้นที่

    อ่าน ternary operator เป็นสามส่วน: เงื่อนไข ? ค่าเมื่อจริง : ค่าเมื่อเท็จ ลองทำนายว่าถ้า pickedName ว่างหรือเป็น Elisha จะเห็นอะไร ก่อนตรวจใน Preview วิธีนี้เหมาะกับการเลือกสองค่า ส่วนเงื่อนไขซับซ้อนอาจแยกเป็น computed property
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน List
    Text(pickedName.isEmpty ? " " : pickedName)
  3. เพิ่มปุ่มใต้ TextField ให้สุ่มจาก names ด้วย randomElement() ซึ่งอาจคืน nil เมื่อรายการว่าง ใช้ if let รับค่าอย่างปลอดภัย และล้างผลใน else ลองกดหลายครั้ง ไม่ต้องคาดหวังว่าทุกครั้งจะได้คนต่างกัน
    แสดง/ซ่อนโค้ด: ContentView.swift — หลัง TextField และ modifiers
    Button("Pick Random Name") {
    if let randomName = names.randomElement() {
        pickedName = randomName
    } else {
        pickedName = ""
    }
}
  4. วาง Divider ระหว่าง TextField กับปุ่ม แล้วสังเกตว่า List มีเส้นแบ่งแถวของตัวเองอยู่แล้ว เปรียบเทียบแนวเริ่มเส้นกับข้อความ
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน Button
    Divider()
ดูภาพอ้างอิงเพิ่มเติมจาก Apple

ตรวจผล / แก้ปัญหา: ปุ่มแสดงชื่อที่มีในรายการได้ ถ้า Text กระโดดขึ้นลงก่อนสุ่ม ให้ตรวจว่าใช้ " " ไม่ใช่ "" ในทางเลือกเมื่อว่าง

เก็บภาพที่ 3: ผลสุ่มชื่อหนึ่งชื่อเหนือรายการ พร้อมช่อง Add Name และปุ่มสุ่ม

4. ควบคุมด้วย Toggle — Use a toggle to customize behavior 10 นาที

Apple · Use a toggle to customize behavior

  1. เพิ่ม state แบบ Bool เพื่อกำหนดว่าจะนำชื่อที่สุ่มได้ออกหรือไม่
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน body
    @State private var shouldRemovePickedName = false
  2. วาง Toggle ระหว่าง Divider กับปุ่มสุ่ม ใช้ binding แบบ Bool ลองเปิดและปิด
    แสดง/ซ่อนโค้ด: ContentView.swift — ก่อน Button
    Toggle("Remove when picked", isOn: $shouldRemovePickedName)
  3. หลัง pickedName = randomName ใน if let เพิ่มเงื่อนไขลบชื่อเฉพาะเมื่อสวิตช์เปิด removeAll ตรวจแต่ละชื่อและลบเมื่อ closure คืน true ลองสวิตช์ปิดก่อน: รายการต้องคงเดิม แล้วเปิด: ชื่อที่เลือกต้องหาย ทุกชื่อที่มีข้อความตรงกันจะถูกลบพร้อมกัน จึงใช้ชื่อสมมติไม่ซ้ำ เช่น Andre C กับ Andre W ลองย่อ return ออกได้สำหรับ closure ที่เป็น expression เดียว แล้วคงรูปแบบที่อ่านเข้าใจ
    แสดง/ซ่อนโค้ด: ContentView.swift — ใน if let หลัง pickedName = randomName
    if shouldRemovePickedName {
    names.removeAll { name in
        return name == randomName
    }
}

ตรวจผล / แก้ปัญหา: ปิด Toggle แล้วสุ่มไม่ลดจำนวน เปิดแล้วลดหนึ่งเมื่อชื่อไม่ซ้ำ สุ่มจนหมดต้องไม่ crash เพราะ else จัดการ nil

เก็บภาพที่ 4: Toggle เปิด ผลสุ่มยังแสดง และชื่อที่เลือกถูกนำออกจากรายการ

5. ปรับป้ายปุ่ม — Use a custom button label 7 นาที

Apple · Use a custom button label

  1. ต่อ style และ font ที่ Button เพื่อให้ปุ่มสำคัญเห็นชัด
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier ของ Button
    .buttonStyle(.borderedProminent)
.font(.title2)
  2. เปลี่ยนจาก Button("Pick Random Name") เป็น Button ที่แยก action กับ label คงโค้ดสุ่มและลบเดิมทั้งหมดใน action ส่วน label เป็น view ที่บอกหน้าตาปุ่ม
    แสดง/ซ่อนโค้ด: ContentView.swift — โครงสร้าง Button; ย้าย action เดิมมาแทน comment
    Button {
    // Keep the existing random-pick action here.
} label: {
    Text("Pick Random Name")
}
  3. เพิ่ม padding ให้ Text ภายใน label ทดลองย้าย padding ไปไว้ก่อน .buttonStyle แล้วสังเกตพื้นที่ภายนอกปุ่ม จากนั้นย้ายกลับภายใน label ตาม tutorial
    แสดง/ซ่อนโค้ด: ContentView.swift — แทน Text ใน label
    Text("Pick Random Name")
    .padding(.vertical, 8)
    .padding(.horizontal, 16)

ตรวจผล / แก้ปัญหา: ปุ่มใหญ่ขึ้นแต่ยังสุ่มและลบตาม Toggle ได้ หากปุ่มไม่ทำงานให้ตรวจว่าได้ย้าย action เดิม ไม่ได้เหลือเฉพาะ comment

6. ปรับงานออกแบบ — Improve your app design 12 นาที

Apple · Improve your app design

  1. เพิ่ม VStack สำหรับสัญลักษณ์และชื่อแอปไว้บนสุดของ VStack หลัก ก่อน Text ผลสุ่ม ใช้ชื่อสัญลักษณ์ตาม tutorial ถ้าอุปกรณ์เก่าไม่มี symbol นี้ ให้ใช้ person.3.fill เป็นทางเลือกพร้อมคงข้อความชื่อแอป
    แสดง/ซ่อนโค้ด: ContentView.swift — บนสุดของ VStack หลัก
    VStack(spacing: 8) {
    Image(systemName: "person.3.sequence.fill")
    Text("Pick-a-Pal")
}
.font(.title)
.bold()
  2. ให้ Image ใช้ tint ของแอป แทนการกำหนดสีคงที่ที่รูป
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier ของ Image
    .foregroundStyle(.tint)
  3. เพิ่ม hierarchical rendering ที่ Image เพื่อให้ส่วนต่าง ๆ ของ symbol มีความทึบต่างกัน ดูผลใน Preview
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier ของ Image
    .symbolRenderingMode(.hierarchical)
  4. ปรับ Text ผลสุ่มให้เด่น แล้วกดสุ่มเพื่อตรวจผลจริง
    แสดง/ซ่อนโค้ด: ContentView.swift — modifiers ของ Text(pickedName.isEmpty ? " " : pickedName)
    .font(.title2)
.bold()
.foregroundStyle(.tint)
  5. ต่อ clipShape ที่ List เพราะรายการนี้อยู่ร่วมกับองค์ประกอบอื่นใน VStack ไม่ได้กินเต็มจอ
    แสดง/ซ่อนโค้ด: ContentView.swift — modifier หลังปีกกาปิด List
    .clipShape(RoundedRectangle(cornerRadius: 8))
  6. Xcode: เปิด Assets → AccentColor ตั้ง RGB เป็น 0.345, 0.337, 0.812 (เทียบประมาณ 88, 86, 207 จาก 255) หรือเลือกสีที่อ่านชัด บน Swift Playgrounds หากแก้ AccentColor ไม่ได้ ให้ต่อ .tint ด้านล่างกับ VStack หลักแทน ตรวจสีของ icon ผลสุ่ม Toggle และปุ่มโดยไม่ใช้สีเป็นสัญญาณเพียงอย่างเดียว
    แสดง/ซ่อนโค้ด: ContentView.swift — ทางเลือก iPad: modifier ของ VStack หลัก
    .tint(Color(red: 0.345, green: 0.337, blue: 0.812))
  7. เปลี่ยนค่าเริ่มต้น names เป็น array ว่างเพื่อให้ผู้ใช้ใส่ชื่อเอง หยุดแล้ว Run ใหม่เพื่อเริ่ม state ใหม่ ไม่พึ่ง Preview ที่อาจเก็บค่าระหว่างแก้ จากนั้นตรวจปุ่มสุ่มตอนว่าง ก่อนเติมชื่อสมมติใหม่เพื่อทดสอบงานออกแบบ
    แสดง/ซ่อนโค้ด: ContentView.swift — แทนค่าเริ่มต้น names
    @State private var names: [String] = []

เพิ่มเติม (ไม่บังคับ) · 5 นาที

ทำให้ข้อความที่มีแต่ช่องว่างไม่ถูกเพิ่มลงรายการ โดยตัดช่องว่างหัวท้ายก่อนตรวจ ทดลองทั้งข้อความว่าง ช่องว่างล้วน และชื่อปกติ ไม่ต้องส่งภาพเพิ่ม

ยินดีด้วย!

คุณสร้างแอปจาก array ใช้ binding รับข้อมูล สุ่มอย่างปลอดภัย และตรวจเงื่อนไขการลบกับการล้างช่องกรอกได้แล้ว เก็บโปรเจกต์ไว้ทบทวน

รวมภาพและส่ง PDF · 10 นาที

ใช้ภาพจากแอปที่คุณทำเอง ไม่ใช้ภาพตัวอย่างของ Apple เรียงหนึ่งภาพต่อหน้าและใส่คำบรรยายสั้น:

  1. ภาพที่ 1: รายการชื่อสมมติสี่แถวที่สร้างจาก names และ ForEach
  2. ภาพที่ 2: รายการที่มีทั้งหมด 5 ชื่อ ได้แก่ ชื่อตัวอย่างเดิม 4 ชื่อและชื่อเล่นของคุณ โดยช่อง Add Name ว่างหลัง Return
  3. ภาพที่ 3: ผลสุ่มชื่อหนึ่งชื่อเหนือรายการ พร้อมช่อง Add Name และปุ่มสุ่ม
  4. ภาพที่ 4: Toggle เปิด ผลสุ่มยังแสดง และชื่อที่เลือกถูกนำออกจากรายการ
  5. ภาพที่ 5: หน้าสุดท้ายหลัง Run ใหม่: ชื่อแอป icon รายการว่าง ช่องกรอก Toggle และปุ่มที่ตกแต่งแล้ว
