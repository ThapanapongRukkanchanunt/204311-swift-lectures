ภารกิจ

1. เพิ่ม list-detail navigation 15 นาที

  1. ครอบ List ด้วย NavigationStack และต่อ .navigationTitle("Requests") กับ List
  2. แทน Text(item.title) ของแต่ละ row ด้วย NavigationLink ตามตัวอย่าง
  3. เปิดสองรายการแล้ว Back กลับให้ครบ

ContentView.swift — ภายใน List closure

NavigationLink {
    Text(item.title).navigationTitle("Request")
} label: {
    Text(item.title)
}

ตรวจผล / แก้ปัญหา: ชื่อใน detail ตรงกับรายการที่กด ถ้าปุ่ม Back ไม่ปรากฏตรวจว่า link อยู่ใน NavigationStack

เก็บภาพที่ 1: หน้ารายละเอียดที่มีชื่อคำขอและ Back

2. เตรียม editor draft 20 นาที

  1. เพิ่ม state ก่อน body ตามตัวอย่าง
  2. ใน destination ของ NavigationLink ครอบ Text ด้วย VStack และเพิ่ม Button("Edit") ที่ตั้ง editingID = item.id, draft = item.title และ showingEditor = true
  3. ต่อ .sheet(isPresented: $showingEditor) กับ NavigationStack ให้มี Form ภายใน และ TextField("Title", text: $draft) กับปุ่ม Cancel ที่ตั้ง showingEditor = false

ContentView.swift — ก่อน body

@State private var editingID: UUID?
@State private var draft = ""
@State private var showingEditor = false

ตรวจผล / แก้ปัญหา: เปิด editor ได้และพิมพ์ไม่เปลี่ยน source จนกด Save ถ้า editor ว่างตรวจว่าเติม draft ก่อนเปิด

เก็บภาพที่ 2: editor ที่มีข้อความ draft ต่างจากเดิม

3. บันทึกตาม ID และเพิ่มรายการ 20 นาที

  1. ใน Form ของ sheet เพิ่ม Save ตามตัวอย่าง ต่อ .disabled(draft.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty)
  2. เพิ่มปุ่ม Add ที่ toolbar ของ List โดยตั้ง editingID = nil, draft = "", showingEditor = true
  3. ปรับ destination Text ให้ค้น title ปัจจุบันจาก requests ด้วย ID ของ item เช่น requests.first(where: { $0.id == item.id })?.title ?? "Request unavailable" เพื่อไม่ยึดสำเนาเก่า

ContentView.swift — ใน Form ของ sheet

Button("Save") {
    let title = draft.trimmingCharacters(in: .whitespacesAndNewlines)
    guard !title.isEmpty else { return }
    if let id = editingID {
        guard let i = requests.firstIndex(where: { $0.id == id }) else { return }
        requests[i].title = title
    } else {
        requests.append(Request(title: title))
    }
    showingEditor = false
}

ตรวจผล / แก้ปัญหา: Save แก้รายการเดิมเมื่อมี ID และเพิ่มเมื่อ ID เป็น nil หากแก้แล้วเกิดรายการซ้ำตรวจแยกสองกรณี

เก็บภาพที่ 3: กลับ list หลัง Save เห็นชื่อใหม่และรายการอื่นคงเดิม

4. ทดสอบ Cancel และเส้นทางกลับ 20 นาที

  1. แก้ชื่อแล้ว Cancel กลับ list ชื่อต้องเดิม เปิดอีกครั้ง draft ต้องเริ่มจากชื่อจริง
  2. ลองเปิด Add พิมพ์แล้วปัดปิด sheet ต้องไม่มีรายการใหม่
  3. ทดสอบ Back หลัง Save และชื่อยาวด้วยข้อความใหญ่ ถ้ารายละเอียดเก่าให้ตรวจการอ่าน record ตาม ID
  4. จงใจส่ง $draft ผิดเป็นตัวแปร saved โดยวิเคราะห์ผลที่จะเกิด ไม่ต้องทำลายข้อมูล จากนั้นตรวจว่าโค้ดจริงใช้ draft เท่านั้น

ตรวจผล / แก้ปัญหา: Cancel และ gesture dismissal ไม่ commit ข้อมูล ส่วน Save สะท้อนกลับ list

เก็บภาพที่ 4: หลัง Cancel กลับ list แล้วชื่อยังเป็นค่าก่อนแก้
