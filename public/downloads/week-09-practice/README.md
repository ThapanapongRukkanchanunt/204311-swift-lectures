# Week 09 practice

Requires SwiftData: provisional Xcode 15+/Swift 5.9 and iOS/iPadOS 17+. In a new SwiftUI App/App playground add both files. In the generated App file add `import SwiftData` and attach `.modelContainer(for: Note.self)` to WindowGroup. Do not create a second @main type. Run, add a study note, terminate/reopen, then delete and reopen. Confirm the note persists and the deletion persists. Example uses explicit saves and rollback. Apple compilation remains pending.
