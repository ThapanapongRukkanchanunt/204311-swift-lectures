# Week 04 practice

Create a new SwiftUI iOS App in Xcode or a new App in Swift Playgrounds. Keep the generated App entry and replace only ContentView.swift with this file. No packages or accounts are needed. Uses established SwiftUI APIs (iOS/iPadOS 16 or later is a provisional example requirement, not the approved course baseline). Run at two widths and with large accessibility text. Expected: both cards remain readable and the screen scrolls. Compare padding/background order in a copy.

Original CS 311 teaching example, not a lab solution. Do not overwrite existing student work. Swift compilation and runtime behavior remain pending verification on the course Macs and iPads.
