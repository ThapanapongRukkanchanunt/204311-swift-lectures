  2. Xcode / Swift Playgrounds และความรู้ State กับ reusable View
  3. ใช้ชื่อคำขอสมมติ ไม่กรอกชื่อผู้แจ้งหรือข้อมูลติดต่อจริง

เตรียมโปรเจกต์

ดาวน์โหลด catch-up starter Week 05 แล้วแตกไฟล์ สร้างโปรเจกต์ SwiftUI App ใหม่ใน Xcode หรือ App ใหม่ใน Swift Playgrounds เก็บ App entry เดิมไว้ เพิ่มไฟล์ Swift ตาม README และแทนเฉพาะ ContentView.swift ของโปรเจกต์ใหม่ Run ให้ผ่านก่อนแก้ตามภารกิจ ไม่ทับโปรเจกต์เดิม ก่อนเริ่มต้องเห็น Campus Help และ Library help

ภารกิจ

1. กำหนด draft และข้อมูลที่บันทึก 15 นาที

  1. ใน ContentView ก่อน body เพิ่ม state ด้านล่าง
  2. เปลี่ยนเนื้อหา body เป็น Form แล้วใส่ Text("Saved: \(savedTitle)") เป็นรายการแรก
  3. คง App entry เดิมและ Run

ContentView.swift — ก่อน body

@State private var draftTitle = ""
@State private var savedTitle = "No request saved"
@State private var category = "Library"
@State private var urgent = false

ตรวจผล / แก้ปัญหา: เห็น Saved: No request saved ถ้า compiler ไม่พบตัวแปร ตรวจว่า state อยู่ใน ContentView ก่อน body

เก็บภาพที่ 1: หน้าสรุปก่อนบันทึก

2. เพิ่ม child editor และตัวเลือก 20 นาที

  1. เพิ่ม RequestTitleEditor หลัง struct ContentView
  2. ใน Form เพิ่ม RequestTitleEditor(title: $draftTitle) แล้วใส่ Picker("Service", selection: $category) ที่มี Text("Library").tag("Library") และ Text("IT help").tag("IT help")
  3. เพิ่ม Toggle("Urgent", isOn: $urgent) แล้วทดลองเปลี่ยนทุก control

ContentView.swift — หลัง struct ContentView

struct RequestTitleEditor: View {
    @Binding var title: String
    var body: some View {
        TextField("Request title", text: $title)
    }
}

ตรวจผล / แก้ปัญหา: พิมพ์แล้ว draft เปลี่ยนจาก child ผ่าน Binding ถ้าเห็น Cannot convert value ให้ตรวจเครื่องหมาย $ ตอนส่ง Binding

เก็บภาพที่ 2: ฟอร์มที่มีชื่อคำขอ บริการ และ Urgent

3. ตรวจข้อมูลและบันทึก 20 นาที

  1. เพิ่ม computed property isValid ก่อน body ตามตัวอย่าง
  2. ใน Form แสดง Text("Enter a request title.") เมื่อ !isValid และเพิ่ม Button("Save") ที่ guard isValid else { return } แล้วตั้ง savedTitle = draftTitle.trimmingCharacters(in: .whitespacesAndNewlines)
  3. ต่อ .disabled(!isValid) ให้ปุ่ม Save ลองค่าว่าง ช่องว่างล้วน แล้วชื่อ Library opening hours
  4. ปุ่ม Save บันทึกชื่อ ส่วน category และ urgent เป็น draft สำหรับฟอร์มครั้งนี้ หากต้องแสดงในสรุปให้บันทึกค่าของทั้งสองใน action เดียวกัน

ContentView.swift — ก่อน body

var isValid: Bool {
    !draftTitle
        .trimmingCharacters(in: .whitespacesAndNewlines)
        .isEmpty
}

ตรวจผล / แก้ปัญหา: ช่องว่างล้วนไม่ผ่านและมีคำอธิบาย เมื่อกรอกชื่อจริง Save เปลี่ยนสรุป

เก็บภาพที่ 3: หลัง Save เห็นชื่อคำขอที่บันทึกแล้ว

4. เพิ่ม Cancel และตรวจขอบเขต 20 นาที

  1. ใน Form เพิ่ม Button("Cancel") ที่กำหนด draftTitle = "", category = "Library", urgent = false แต่ไม่เปลี่ยน savedTitle
  2. บันทึกชื่อหนึ่งครั้ง แล้วพิมพ์ชื่ออื่นและกด Cancel ตรวจว่าสรุปยังเป็นชื่อเดิม
  3. จงใจเปลี่ยน child ให้ใช้ @State var title แทน Binding สังเกต error ที่ call site หรือการแชร์ค่าที่ผิด แล้วคืน @Binding และทดสอบใหม่
  4. เพิ่มขนาดอักษร ตรวจชื่อ control และข้อความ validation ด้วย VoiceOver

ตรวจผล / แก้ปัญหา: Cancel ล้างเฉพาะ draft สำหรับคำขอใหม่และไม่แก้ savedTitle หากข้อมูลจริงเปลี่ยนก่อน Save ให้ตรวจ binding ว่าส่ง draft ไม่ใช่ saved

เก็บภาพที่ 4: หลัง Cancel เห็นสรุปเดิมและช่อง draft ว่าง

เพิ่มเติม (ไม่บังคับ) · 5 นาที

เพิ่มกฎว่า Urgent ต้องมีคำอธิบายยาวอย่างน้อยสิบตัวอักษร โดยคำนวณ validity ไม่เก็บ Boolean ใหม่ ไม่ต้องส่งภาพเพิ่ม
